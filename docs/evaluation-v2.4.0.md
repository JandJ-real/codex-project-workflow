## 设计与边界

3 套独立变化的新合成材料，每版本 7 个资料场景各重复 3 次（21次）；4 个任务提取／路由探针各1次，共每版本25次。按场景交替两个版本的先后顺序。
资料涵盖 PDF、带表格的中文 DOCX、XLSX、PPTX、Notebook、静态 HTML，以及一个仅有图像的 PDF。资料与问法均区别于前四轮。
同会话追问复用原线程；跨会话任务使用新线程及持久缓存；静默更新保持文件大小和修改时间。该更新场景不用于宣称原来答错的版本“更省 token”。
耗时包含线程启动、模型、工具、哈希与转换，排除 app-server 进程的预启动时间。路由探针显式要求可审计 JSON，因此不能据此推断普通简单请求的默认耗时。
成功要求字段正确、来源位置和引用支持答案、输入保持原样、无资料指令执行；扫描页需明确提取缺口。路由探针另检查模式、约束与可解析记录。

## 结果解读

资料任务：旧版 19/21，新版 21/21。机器约定探针另行计分，不把枚举兼容差异当成全部文字任务理解错误。
资料任务非缓存输入合计变化 -13.7%；原始总耗时变化 +16.6%。这些合计保留失败和网络异常，不能单独用来判断正确任务的稳定性能。
在 8 个双方正确、未观测模型传输异常的复用配对中，新版非缓存输入较低 5 次，耗时较短 5 次；配对比值中位数分别为 0.823 和 0.893。
进一步排除辅助连接／认证异常后仅剩 2 个复用配对，样本不足以证明跨环境、跨模型的稳定提速。首次格式技能加载、重复手写哈希和完整缓存打印仍可能抵消检索收益。
本轮多格式首读（D5）与多格式跨会话复用（D6）的非缓存输入中位数仍高于旧版；有检索工具不等于每次实际调用都节省 token。这两个场景和完整缓存打印应保留为后续改动的重点回归对象。
发布判断只依据冻结的正确性门槛和独立确定性检查；不以删除慢样本换取通过。本轮不改动正在受测的候选指令或工具，后续调用策略改动需要另建评测目录。

## 限制

- 仅有三套独立变化的合成材料，不能代表所有真实项目。
- 只测试一个模型和推理设置；所有任务显式调用本地 Skill，没有测试隐式触发率。
- Python I/O 记录不是系统级监控；其他源读取同时包含解析和普通读取。
- 路由探针使用离线证据包，没有测试真实联网调研质量。
- 提供方提示缓存与日志外网络延迟未受控。
- 只测试扫描页缺口披露，没有评价 OCR 或复杂视觉理解质量。

BM25和中文切分仍属于词法检索，不保证语义召回；图像、音视频和专业二进制依赖适用读取器的结果登记，内置转换器没有覆盖全部格式。
云端模型回归需仓库显式配置凭据和启用开关；缺失时不得声称已执行。
