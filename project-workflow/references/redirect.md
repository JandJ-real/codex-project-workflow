# 纠偏与必要改线

先以用户最新明确要求和项目有效记录确定当前目标与边界。不要把过时计划强加给用户，也不要因一个新想法自行推翻已选路线。

```text
当前任务与阶段：这次工作服务于哪个既定交付物。
发生的偏离：哪些提议或动作超出范围。
候选记录：可保留到后续的想法、依据和验证方法。
阻塞证据：维持原路线为何不能完成当前目标，若无证据则不称为必须改线。
最小调整与影响：需要改什么，已有成果、成本和验收怎样受影响。
需要用户决定的选项：仅列仍未明确的重要选择。
```

没有真实阻塞时，记录范围外候选并继续授权任务。需要改线时准备具体可比较的方案，不只说“是否允许优化”。已有通过且相关条件未变的检查直接复用。
