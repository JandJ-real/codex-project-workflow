# 恢复与继续项目

适用于换聊天、压缩上下文、长时间中断或用户要求继续已启用的工作流。

```text
继续目标：用户指定的任务，或当前阶段已记录的下一步。
有效状态：当前阶段、基础方案、关键约束、已有结果和来源入口。
新增变化：用户本次修正和已知文件变化；没有信息时不编造变化。
执行范围：沿用仍有效的授权，并尊重本次新增边界。
```

- 先读取当前需要的项目状态，不重新通读全部原始资料和历史记录。
- 复杂文件先校验内容哈希并检索现有可读表示；只刷新变化文件，保留提取缺口与已核对位置。哈希校验不等于重新解析。
- 状态与实际源文件有冲突、摘要缺少精确信息或需要编辑时，定向回读、修正过时状态。
- 用简短说明让用户知道从哪一步继续，然后推进已授权任务，不重新选择已定路线。
- 无有效状态且无法确定继续内容时，补读最相关记录；仍缺关键目标则集中询问，不凭记忆伪造进度。
